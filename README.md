# arifstudio.net

The portfolio site for arifstudio, the studio of Intern Architect Arif. It is a static site with no build step, hosted on GitHub Pages.

- `index.html`: the page. To edit projects, search for `const P=[`.
- `assets/img`: renders and drawings as WebP. `-s` files are thumbnails and `-l` files are full size.
- `assets/media`: the hero loop and the studio film.
- `CNAME`: the custom domain.
